# Claims inventory

This table lists every guarantee the verification tools make or the notes in `docs/` claim,
one per row, at commit `b83b9544ccdef3701bf90383cd56d10ea2297787`. It is the skeleton of the
theme documents: each row names the theme that owns it, and that document states the claim
as a proposition and gives its proof, or says what stands in for one.

## How to read a row

- **ID** is `A`, `B`, `N`, or `T` and a number, for themes (a) cones, (b) z3, (c) native, and
  (d) TLC. `D1` to `D23` are not rows: they are the definitions of
  [semantics.md](./semantics.md).
- **Claim** is stated in the notation of [semantics.md](./semantics.md). `T` is
  `T_β(M)` (D13). `C` is a cone `T|W` (D15), `R` the cone reduced by its independent
  sub-lifecycle, `Q` the quotient of a run by slot permutations. `⊨` is "the verdict is
  `ok`", `⊭` "the verdict is `counterexample`".
- **Where** is the note and section that states the claim.
- **Evidence** is one or more of these classes, the strongest first:
  - **P** paper proof. `P-full` is an argument a reader can check step by step; `P-sketch`
    names the facts it rests on without deriving them.
  - **M** mechanically checked: a Kani harness (bounded model checking of a Rust function
    on every input up to a bound) or a shadow twin (a reference implementation that a
    `--features shadow` build runs beside the fast one, panicking on any difference, on the
    inputs the CI runs give it). A twin checks two implementations against each other, not
    against a specification.
  - **D** differentially tested: the engine corpus, the sample comparison, the random-model
    sweep, or the mutation run. Each names its test.
  - **R** runtime-checked: every user run checks the claim on its own output and reports a
    tool error when it fails. This is evidence that a wrong answer of that kind is not
    printed, not that the answer is computed correctly.
  - **A** assumed: rests on a component the project does not verify (z3, TLC, the JVM, the
    TLA+ translation's faithfulness, rlimit determinism).
  - **none written**: the claim is true by construction of the code, as far as the code
    shows, but no note argues it.
  - **none**: no evidence found.

  The classes P, M, D, A, and none are the ones the inventory was asked for; R and "none
  written" are added here because several claims rest on exactly that kind of support.
- **unread@pin** marks a part of a row whose cited code its theme document did not read at
  the document's pinned commit: that part rests on the survey's reading for this inventory,
  on another note, or on the named tests alone. A part without the marker was checked against
  the code at the pinned commit. The theme documents use the same marker in their text and
  summary tables.
- **Code** and **Tests** cite `crate/src/path.rs::symbol`; `core` is
  `crates/rdra-ish-core/src/lifecycle`, `cli` is `crates/rdra-ish-cli`, `emit` is
  `crates/rdra-ish-emit/src`.
- **Open** names an item of the index's [Open problems](./README.md#open-problems) that
  bears on the row.

## (b) Theorem proving with z3

The theme document is [z3.md](./z3.md), which states each row below as a proposition. Every
row in this section assumes **z3 answers `unsat` only for unsatisfiable queries** (H1 of
[z3.md](./z3.md#the-soundness-theorem), Theorem 1) **and that the prover takes each answer for
the check that asked it** (H4: `Z3::exec` reads a batch's output up to an echoed marker and
`Solver::check_sat` reads its first line as the answer; see
[z3.md](./z3.md#the-answer-reader)). No
code under `core/prove/` has a Kani harness or a shadow twin. `prove/encode.rs::Enc::compare`
re-implements `expr.rs::compare`, whose Kani harnesses do not reach the SMT mirror; only
differential tests tie the two. Below, `Enc_n` is the z3 encoding of `T` with any number of
rows per entity, and `Enc` the encoding for every `n` at once (an uninterpreted sort per
entity).

## (d) Agreement with TLC

Every row in this section rests on an assumption no test can remove: **TLC (1.7.4, 1.8.0) is
correct**. The TLA+ printer (`emit/tla/mod.rs::print`, `emit/tla/module.rs`,

its CI evidence is about the devShell's TLC, which `flake.nix` pins to the 1.8.0 pre-release on JDK 25.
